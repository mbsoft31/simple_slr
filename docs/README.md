simple_slr Documentation
========================

This repository supports a transparent, reproducible scoping/systematic review workflow for ML/vision approaches to plant disease and pest detection. The docs describe how to run searches, deduplicate records, prepare PRISMA counts, generate screening exports, extract data, and report results.

Guides
------

- Quickstart: docs/quickstart.md
- Repository Structure: docs/architecture.md
- Deduplication: docs/deduplication.md
- PRISMA Counts: docs/prisma_counts.md
- Screening Export: docs/screening_export.md
- Source Coverage (wide): docs/source_coverage.md
- Extraction Template & Codebook: docs/extraction_template.md
- Review Guidance (for reviewers, team, supervisors): docs/review_guidance.md

All commands assume repository root as the working directory.
